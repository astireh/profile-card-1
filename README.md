# Карточка пользователя
## HTML-код
```HTML

<!DOCTYPE html> <!-- *Объявляет документ как HTML5.* -->
<html lang="en"> <!-- *Открывает корневой HTML-элемент и указывает язык документа.* -->
<head> <!-- *Открывает секцию служебной информации документа.* -->
      <meta charset="UTF-8"> <!-- *Устанавливает кодировку UTF-8 для корректного отображения символов.* -->
      <meta name="viewport" content="width=device-width, initial-scale=1.0"> <!-- *Настраивает масштаб страницы для корректного отображения на мобильных устройствах.* -->
      <title>Карточка пользователя</title> <!-- *Задаёт заголовок страницы во вкладке браузера.* -->
      <link rel="stylesheet" href="styles.css"> <!-- *Подключает внешний CSS-файл styles.css.* -->
</head> <!-- *Закрывает секцию служебной информации документа.* -->
<body> <!-- *Открывает тело страницы с видимым содержимым.* -->
      <div class = "card"> <!-- *Создаёт основной контейнер карточки и задаёт ему класс card.* -->
            <img src="images/image.png" alt="Антон Смирнов" id="imgg" > <!-- *Добавляет изображение пользователя: src указывает путь к файлу, alt — альтернативный текст, id — уникальный идентификатор.* -->
            <div class = "content"> <!-- *Создаёт контейнер для текста и кнопки и задаёт ему класс content.* -->
                  <div class="text"> <!-- *Группирует имя и профессию пользователя в отдельный контейнер.* -->
                        <p class="name">Антон Смирнов</p> <!-- *Выводит имя пользователя и задаёт класс name для стилизации.* -->
                        <p class="profession">UX/UI дизайнер</p> <!-- *Выводит профессию пользователя и задаёт класс profession для стилизации.* -->
                  </div> <!-- *Закрывает контейнер text.* -->
                  <button name="Knopka">Написать</button> <!-- *Создаёт кнопку с именем Knopka и текстом «Написать».* -->
            </div> <!-- *Закрывает контейнер content.* -->
      </div> <!-- *Закрывает основной контейнер карточки.* -->
</body> <!-- *Закрывает тело документа.* -->
</html> <!-- *Закрывает корневой HTML-элемент.* -->
```

## CSS-код
```css
body { /* *Выбирает элемент body как основной контейнер страницы.* */

.content { /* *Выбирает элементы с классом content.* */
```
